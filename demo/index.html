Run it yourself

Ten lines, two registries.

Inference code lives on GitHub, weights on Hugging Face. Both are public and self-hostable.

GitHub · CAMEL-ECG/CAMEL-inference

Minimal inference with a single ECG file (NumPy or WFDB).

git clone https://github.com/CAMEL-ECG/CAMEL-inference
cd CAMEL-inference
pip install -e .

from camel_ecg import CAMELForecaster
import numpy as np

ecg = np.load("ecg.npy")                     # shape (12, T)
model = CAMELForecaster.from_pretrained("CAMEL-ECG/camel-forecast")
out = model.forecast(ecg, horizon_min=3)
print(out.label, out.citations)

Hugging Face · CAMEL-ECG

Load weights directly with from_pretrained.

from transformers import AutoProcessor, AutoModelForCausalLM
import torch, numpy as np

proc  = AutoProcessor.from_pretrained("CAMEL-ECG/camel-forecast")
model = AutoModelForCausalLM.from_pretrained(
    "CAMEL-ECG/camel-forecast", torch_dtype=torch.bfloat16, device_map="auto")

inputs = proc(ecg=np.load("ecg.npy"),
              text="Forecast the next 3 minutes.",
              return_tensors="pt").to(model.device)
print(proc.decode(model.generate(**inputs, max_new_tokens=256)[0]))
